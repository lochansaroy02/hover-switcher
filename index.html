How it works

  1. 1

    Hover

    The extension asks YouTube for the same account list its own menu uses, using the session you're already signed into.

  2. 2

    Pick

    You see each account's name, handle, avatar and a check on the active one. Click any other account.

  3. 3

    Switched

    YouTube's own switch runs behind the scenes, so the change sticks. The page reloads where you left off.

Install in under a minute

Get the extension folder, then load it into your browser in developer mode.

  1. Open chrome://extensions (or brave://extensions).
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked and choose the extension folder (the one containing manifest.json).
  4. Reload any open YouTube tab and hover your avatar.
  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on… and select manifest.json.
  3. On Firefox older than 127, allow access: Extensions menu → Hover Switcher → Always allow on www.youtube.com.
  4. Reload YouTube and hover your avatar. Temporary add-ons are removed when Firefox restarts.

Questions

Does it see my password or send my data anywhere?

No. It runs only on www.youtube.com and reads the account list YouTube already shows you, using your existing session. Nothing is sent to any other server.

Why does the page reload when I switch?

That's how YouTube applies a new account. The extension brings you back to the same page and timestamp.

Could it stop working?

Possibly. It relies on an undocumented YouTube endpoint, which YouTube can change at any time. If the list ever fails to load, the dropdown shows a retry button, and the console logs (prefixed [YT-Switcher]) show what went wrong.

Does it work on YouTube Music or Studio?

Not yet. It runs only on the main www.youtube.com site and does nothing anywhere else.
